# DeepSeek Chat App

This is a simple AI chatbot project using DeepSeek R1 model through OpenRouter API.

I built this to understand how to connect an LLM API with Python and get responses.

## What this project does

- Takes user input
- Sends it to DeepSeek model
- Gets a response from API
- Prints the output

## Tech used

- Python
- Requests
- OpenRouter API
- DeepSeek R1

## How to run

1. Clone the repo

git clone https://github.com/your-username/deepseek-chat-app.git

2. Go to folder

cd deepseek-chat-app

3. Install requirements

pip install requests

4. Add your API key in code

API_KEY = "your_api_key_here"

5. Run the file

python app.py

## Note

Do not share your API key publicly.

## Why I made this

I am learning Generative AI and wanted to try a basic chatbot using an API.

This is a starting project before building more advanced AI apps.
